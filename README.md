# 🚀 Programming Hero — Assignment 1

## AI-Driven Full Stack Web Engineer Course

A modern and responsive **Developer Conference Landing Page** built as the first assignment of the **Programming Hero AI-Driven Full Stack Web Engineer Course**.

This project focuses on creating a clean, professional conference website UI using **HTML5 and CSS3**, with sections for the event hero, speakers, pricing plans, attendee reviews, and footer.

---

## 🌐 Live Demo

🔗 Live Website: https://fuyad254.github.io/Assignment-1/


---

## 📸 Project Overview

The website is designed for a fictional developer conference called **DevConf 2026**, where developers, engineers, founders, and builders can join technical talks, workshops, networking sessions, and other activities.

The design follows a modern and minimal interface with a professional blue-and-white color palette.

---

## ✨ Features

* 🎯 Modern developer conference landing page
* 📱 Responsive and clean layout
* 🧭 Navigation bar with conference sections
* 🖼️ Full-width hero/banner section
* 🎤 Speaker showcase section
* 💳 Multiple conference pricing plans
* ⭐ Attendee testimonial/review section
* 🎨 Modern card-based UI
* 🖱️ Interactive hover effects
* 📐 Flexbox and CSS Grid based layouts
* 🔤 Google Fonts integration
* 🦶 Clean and professional footer
* ⚡ Lightweight frontend implementation

## 📑 Website Sections

### 1. Navigation Bar

The navigation section contains:

* Speakers
* Schedule
* Tracks
* Venue
* Blog
* Register Now button

---

### 2. Hero Section

The hero section introduces the conference with:

> **Code. Connect. Create**

It also includes a short event description and a prominent **Register Now** call-to-action button.

---

### 3. Meet the Speakers

A dedicated speaker section showcases conference speakers along with their:

* Profile image
* Expertise
* Name
* Professional designation

Example speakers include:

* Andrej Karpathy
* Demis Hassabis
* Gray Marcus
* Mustafa Suleyman

---

### 4. Conference Pricing

The pricing section provides three different registration plans:

#### 💼 Standard — $399

* Access to all 3 conference days
* 48 curated technical talks
* 2 workshop sessions
* Networking lunch & coffee breaks
* Conference swag bag
* Digital recordings

#### 🚀 Pro — $749

* Everything in Standard
* Unlimited workshop access
* Speaker meet & greet
* VIP networking dinner
* Lifetime recording access
* 1-on-1 mentorship

#### 🏢 Team — $5,999

* Everything in Pro
* 10 seats
* Dedicated team lounge
* Private workshop booking
* Company logo placement
* Recruitment booth
* Priority customer support

### 5. Attendee Reviews

The testimonial section displays feedback from previous conference attendees.

It includes:

* Attendee profile
* Name
* Profession
* Star rating
* Review

This section helps make the conference website feel more realistic and engaging.
